# تدقيق شامل لموقع ركن التطور مصر

**الموقع:** https://www.rukn-eltatawer.com/eg/  
**تاريخ الفحص:** 16 سبتمبر 2026  
**طريقة الفحص:** واجهة ووردبريس REST بحساب مسؤول + تحليل HTML/SEO + تصفح بصري لسطح المكتب والجوال.

هذا التقرير يستخرج الأخطاء والنواقص في الموقع والقالب كما هي على الموقع الحي. لم يُغيَّر شيء على ووردبريس أثناء الفحص.

## خلاصة تنفيذية

الموقع يعمل كتثبيت ووردبريس مستقل تحت `/eg/` بقالب **KAYAN Theme 1.4.2** (بقايا **YourColor**). نُشر عليه **842 مقالاً** (421 عربي + 421 إنجليزي) لكن الطبقة التسويقية للقالب **غير مكتملة لمصر**: قائمة فارغة، نصوص نائبة ظاهرة للزائر، نسخة إنجليزية للصفحة الرئيسية غير موجودة، وتصنيفات إنجليزية تالفة.

| المؤشر | القيمة على الموقع الحي |
|---|---|
| القالب النشط | `kayan-theme` 1.4.2 — textdomain: `yourcolor` |
| المقالات | 842 منشورة — **صفر صورة بارزة** |
| أنواع القالب المخصصة | خدمات / تقييمات / أسئلة / أسعار / أعمال = **كلها 0** |
| عناصر القائمة في ووردبريس | 9 عناصر **مكررة**، بينما `<nav class="menu"></nav>` **فارغ** |
| مكتبة الوسائط | 6 ملفات فقط (شعارات) |
| الصفحة الأمامية | `show_on_front = posts` وليست صفحة ثابتة |

**الحكم:** البنية والمقالات موجودة، لكن القالب وإعدادات مصر غير جاهزين للثقة التجارية أو للفهرسة السليمة.

## حرجة — تظهر للزائر فوراً

### 1. نصوص نائبة من القالب ظاهرة في الصفحة الرئيسية

في قسم «أرقامنا» يظهر حرفياً:

- `[[عدد المشاريع]]` فوق تسمية «مشروع منفّذ»
- `[[سنة التأسيس]]` فوق تسمية «في مصر منذ»

هذه حقول دمج لم تُستبدل بأرقام مصر. مصداقية الشركة تُهدم من أول تمريرة.

لقطة: `docs/audit-screenshots/homepage_placeholder_counters.webp`

### 2. قائمة التنقل فارغة

HTML الرأس:

```html
<nav class="menu"></nav>
```

قائمة الهامبرغر لا تحتوي روابط (رئيسية / خدمات / تواصل / عن الموقع). يظهر فقط بحث + زر واتساب. في ووردبريس قائمة باسم `Egypt` فيها 9 عناصر لكنها **مكررة ثلاث مرات** (الرئيسية ×3، تواصل ×2، عن الموقع ×2، خريطة ×2) وعناوينها مختلطة عربي/إنجليزي مثل:

`تواصل معنا — ركن التطور مصر / Contact Egypt`

القالب لا يطبع هذه القائمة في `<nav class="menu">`.

لقطة: `docs/audit-screenshots/empty_hamburger_menu.webp`

### 3. مسار الإنجليزية `/eg/en/` يعرض الصفحة العربية نفسها

- `<html lang="ar" dir="rtl">` على مسار الإنجليزية.
- نفس الـ H1 العربي ونفس «اختر الإمارة» ونفس النصوص النائبة.
- `canonical` التالف: `https://rukn-eltatawer.com/eg/eg/en/`
- Polylang: `home_url` للإنجليزية = `/eg/en/` لكن **لا توجد صفحة رئيسية إنجليزية** (`page_on_front = 0` للغتين).

لقطة: `docs/audit-screenshots/english_url_shows_arabic_home.webp`

### 4. مقالات إنجليزية على الصفحة الرئيسية العربية

السبب البرمجي: **318 مقالاً إنجليزياً** مصنَّف تحت `category-cleaning-en-en` رغم أن معظمها تشطيبات وديكور.

صفحة التواصل:

## القالب KAYAN / بقايا الخليج وYourColor

القالب منقول من نسخة الإمارات/الخليج ولم يُستكمل توطينه لمصر.

| المشكلة | الدليل |
|---|---|
| تسمية «إمارة» في مصر | `aria-label="اختر الإمارة"` ووسم الخطوة 2: **اختر الإمارة** رغم أن الخيارات محافظات مصرية |
| تعليق CSS داخلي | «خريطة الإمارات الكحلية + كروت المدن» |
| textdomain | `yourcolor` — 37 ظهور `YourColor` في HTML الرئيسية |
| عنصر غير قياسي | `<root>` و`body mode="light" class="before-start"` |
| `@font-face` تالف | `{2font-family: "Plus Jakarta Sans"` و`{1font-family` — كسر CSS |
| preload فارغ | `<link rel="preload" as="font">` بلا `href` |
| أيقونات من موقع الإمارات | 53 صورة من `www.rukn-eltatawer.com/wp-content/uploads/icon/` وليس من `/eg/` |
| Schema فارغ | `LocalBusiness` بكل الحقول فارغة بما فيها `aggregateRating` (خطر تقييم وهمي فارغ) |
| تكرار JSON-LD | Rank Math + سكربت القالب + WebSite SearchAction مكرر |
| أنواع محتوى القالب فارغة | `services`, `reviews`, `faqs`, `pricing`, `portfolio` = 0 — الصفحة الرئيسية تعتمد على HTML ثابت داخل القالب لا على بيانات ووردبريس |
| أرشيف المدن لا يعمل | `/eg/cities/fifth-settlement/` يعيد التوجيه للرئيسية |
| رابط التذييل «المدونة» | `/eg/blog/` يعيد التوجيه للرئيسية لأن الصفحة غير موجودة |
| عدّادات الهيرو غير متسقة | اللوحة الزجاجية تعرض أحياناً **11 محافظة / 15 خدمة** بينما `data-count` في HTML = **16 و 12** وقسم الأرقام يعرض 16 و 12 |

نصوص القالب الثابتة على الرئيسية (الخدمات، الأسئلة، المحافظات) جيدة عربياً، لكنها **غير مربوطة** بأنواع المنشورات المخصصة، لذلك أي تعديل في ووردبريس لا يظهر هناك.

## SEO تقني

### روابط canonical وhreflang خاطئة

- الرئيسية: `canonical` و`og:url` = `https://rukn-eltatawer.com/eg/eg/` (تكرار `/eg/`)
- الرئيسية الإنجليزية: `https://rukn-eltatawer.com/eg/eg/en/`
- مقال إنجليزي حيّ على `/eg/en/{slug}/` بينما `hreflang="en"` يشير إلى `/eg/{slug}-en/` **بدون** `/en/`
- لا يوجد `hreflang="x-default"`
- صفحتان `meta name="description"` في `<head>` (قالب + Rank Math)

### robots.txt معطوب

طلب `https://rukn-eltatawer.com/eg/robots.txt` يعيد **HTML الصفحة الرئيسية** وليس ملف robots. خريطة XML تعمل:

- https://rukn-eltatawer.com/eg/sitemap_index.xml
- لكنها تتضمن تصنيفات تالفة مثل  
  `/eg/en/category/غير-مصنف-en/` و`finishing-decor-en-en` و`cleaning-en-en`

### الصفحة الأمامية ليست صفحة ثابتة

`show_on_front = posts` فيسبب:

- `<link rel="next" href="https://rukn-eltatawer.com/eg/page/2/">` على الرئيسية
- `/eg/page/2/` صفحة ترقيم مدونة بهوية الموقع بلا H1 واضح
- محركات البحث ترى الرئيسية كأرشيف مقالات لا كصفحة خدمة

### المقالات بلا وسائط

- 842/842 `featured_media = 0`
- محتوى المقالات **بدون `<img>`** (ملفات CSV الأصلية كانت تشير إلى `.webp` نسبية لم تُرفع)
- صورة OG لكل المقالات هي صورة الشركة العامة `rukn-eltatawer-picture.webp`
- في «مقالات ذات صلة» تظهر بطاقات بيضاء/رمادية بلا صورة

لقطة: `docs/audit-screenshots/article_related_missing_images.webp`

### عنوان الرئيسية ضعيف

`<title>ركن التطور - مصر</title>` فقط — أقصر من وصف OG المختلط عربي/إنجليزي.

### مقال عربي: H1 مكرر

القالب يطبع عنوان المنشور كـ H1، والمحتوى يبدأ بـ H1 آخر داخل المقال. مثال التجمع الخامس:

1. `تشطيب شقق في التجمع الخامس`
2. `تشطيب شقق في التجمع الخامس — دليل شامل 2026`

## Polylang والتصنيفات

إعدادات Polylang الحالية:

- اللغات: `ar` (افتراضي) + `en`
- `hide_default: true` و`browser: true` (إعادة توجيه حسب لغة المتصفح — مصدر قلق للزحف والـUX)
- **`post_types` لا يشمل `post` ولا `page`** — فقط أنواع KAYAN الفارغة  
  النتيجة: المقالات العربية والإنجليزية **غير مربوطة كترجمات رسمية**، والإنجليزية تعتمد على لاحقة `-en` فقط
- `html lang="ar" dir="rtl"` على المقال الإنجليزي رغم أن النص إنجليزي — تجربة LTR مكسورة

### تصنيف إنجليزي تالف (أرقام من class_list)

| تصنيف | عدد المقالات |
|---|---|
| `cleaning-en-en` | 318 |
| `finishing-decor-en-en` | 152 |
| `craftsmen-en-en` | 125 |
| `category---en` (slug فارغ/معطوب) | 96 |
| `craftsmen-en` | 27 |

`service_categories` المعرفة في القالب كلها `count = 0` بينما المقالات تستخدم `category` العادي. مسار REST `/wp/v2/categories` يعيد 404 (المسار مُعطَّل أو محجوب) رغم أن أرشيف `/category/finishing-decor/` يعمل.

### مدن ووسوم مكررة

- 131 مدينة: 45 عربي + 87 لاتيني، **44 اسماً مكرراً** (Cairo/القاهرة كمصطلحات منفصلة بلا `parent`)
- 29 مدينة بعدد مقالات 0
- 198 وسماً: النسخ العربية غالباً `count=0` والإنجليزية `-en` هي المستخدمة

## المحتوى والمعلومات التجارية

### رقمان مصريان مختلفان في المقالات

- واتساب/هاتف الموقع والرئيسية: **+201556644443** (متسق مع تذييل FAQ)
- داخل قوالب المقال يظهر أيضاً **+201007707742** في روابط `tel:` و`wa.me`
- الصفحة الرئيسية **لا تحتوي أي `tel:`** — واتساب فقط

### لا عنوان / لا بريد / لا ساعات موثّقة

- Schema المنظمة: دوام `09:00-17:00` كل أيام الأسبوع بما فيها الجمعة بلا توضيح
- `LocalBusiness` فارغ: لا شارع ولا مدينة ولا دولة ولا هاتف ولا `priceRange`
- لا `mailto:`
- لا روابط فيسبوك/إنستغرام حقيقية في التذييل (أيقونات المشاركة في الصفحات الداخلية مكسورة)

### تغطية جغرافية غير متسقة

- الواجهة تقول «12 محافظة»
- المقالات تغطي أحياء وكمبوندات إضافية (التجمع، الشيخ زايد، مدينتي، العاصمة الإدارية، المحلة، المنيا، قنا، سوهاج…) غير ممثلة في محدِّد «الإمارة»
- أرشيف المدينة لا يفتح

### المقالات ذات الصلة غير ذات صلة

تحت مقال «تشطيب شقق في التجمع الخامس» تظهر: تفصيل مطابخ المحلة، ديكور الزمالك، ديكور الإسماعيلية، **دريسينج روم في المنيا** (ترجمة حرفية لـ Dressing room). لا ربط دلالي بالمدينة أو الخدمة.

### تعليقات مفعّلة على المقالات

«لم يتم إضافة تعليقات لهذا المقال» + زر إرسال تعليق — ضوضاء UX ومخاطر سبام بلا فائدة تسويقية.

### صفحات أساسية ناقصة

لا توجد صفحات خدمة حقيقية من CPT، لا سياسة ملفات تعريف، لا شروط استخدام بالعربية فقط، صفحة Privacy Policy الإنجليزية ما زالت **مسودة** (`page_id=3`). خريطة HTML عناوينها مختلطة `HTML Sitemap / خريطة الموقع`.

## أولوية الإصلاح المقترحة

### فوراً (ثقة الزائر)

1. استبدال `[[عدد المشاريع]]` و`[[سنة التأسيس]]` بأرقام حقيقية أو حذف القسم.
2. إصلاح `<nav>` وربط قائمة واحدة غير مكررة بعربية فقط (خدمات، مدونة، تواصل، عن الموقع).
3. تغيير تسمية «اختر الإمارة» → «اختر المحافظة».
4. منع المقالات الإنجليزية من الظهور على الرئيسية العربية (استعلام Polylang / استبعاد `-en`).
5. توحيد رقم الهاتف على رقم مصر المعتمد وحذف `01007707742` إن لم يعد مستخدماً.

### SEO / لغة

6. تفعيل `post` و`page` في Polylang وربط كل زوج عربي/إنجليزي.
7. بناء صفحة رئيسية إنجليزية حقيقية أو إغلاق `/eg/en/` بـ noindex إلى حين جاهزيتها.
8. ضبط `html lang` و`dir` حسب اللغة.
9. تصحيح canonical (إزالة `/eg/eg/`) وhreflang و`x-default`.
10. إصلاح `robots.txt`.
11. تعيين صفحة أمامية ثابتة وإيقاف `/page/2/` كامتداد للرئيسية.
12. إعادة توزيع التصنيفات الإنجليزية وإصلاح `cleaning-en-en` و`---en` و`غير مصنف-en`.

### محتوى القالب

13. ملء CPT: خدمات، أسئلة، أعمال، تقييمات — أو إيقاف اعتماد القالب عليها.
14. رفع صور بارزة ومحتوى مرئي؛ إيقاف البطاقات الرمادية.
15. فصل صفحات عربي/إنجليزي (تواصل، عن، خصوصية) بدل دمج فقرة English داخل الصفحة العربية.
16. إضافة نموذج تواصل أو الاكتفاء الواضح بواتساب مع `tel:`.
17. إصلاح أرشيف `/cities/` و`/blog/`.
18. إصلاح CSS التالف (`2font-family`) وpreload الفارغ، ونسخ الأيقونات إلى `/eg/` بدل السحب من موقع الإمارات.

### أمان

19. إغلاق أو تقييد WPVibe على بيئة الإنتاج إن لم تكن هناك حاجة يومية.
20. إخفاء `X-Powered-By` وإضافة رؤوس أمنية على الصفحات العامة.
21. إغلاق التعليقات على مقالات الخدمة.
