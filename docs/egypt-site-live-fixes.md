## ما تعذّر إصلاحه بدون تعديل ملفات القالب

`DISALLOW_FILE_EDIT` يمنع كتابة ملفات `kayan-theme`. هذه البنود تحتاج رفع قالب محدَّث على الاستضافة:

| البند | السبب |
|---|---|
| «اختر الإمارة» في مصدر HTML | نص ثابت في `rukn_finder.php` — الاستبدال الحالي عبر JS فقط |
| `canonical` = `/eg/eg/` و`/eg/eg/en/` | يخرجه Rank Math/KAYAN SEO من `home_url` مع المسار الفرعي |
| `<html lang="ar" dir="rtl">` على `/eg/en/` | ثابت في `#header/part.php` |
| `/eg/robots.txt` يعيد HTML | ووردبريس تحت `/eg/`؛ `robots.txt` الحقيقي على جذر النطاق (موقع الإمارات) |
| تفعيل Polylang على `post`/`page` | الحفظ يُرفض/يُعاد للكتلة الافتراضية (CPT القالب فقط) |
| مسار الإنجليزية `/eg/en/` يعرض الرئيسية العربية | لا صفحة أمامية إنجليزية و`page_on_front=0` |
